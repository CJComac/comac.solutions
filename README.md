# Web app portfolio

A static, GitHub Pages-ready portfolio site. Open `index.html` locally to preview it.

## Personalize it

1. In `index.html`, replace every `Your Name`, `hello@yourdomain.com`, and `your-github-username` placeholder.
2. Replace the three sample project names, descriptions, technology tags, and links in the **Selected work** section.
3. Keep the CSS-built project previews or replace each `.project-visual` content with an image or screenshot of your work.

## Publish on GitHub Pages

In the repository on GitHub, go to **Settings → Pages**, choose **Deploy from a branch**, then select the `main` branch and the `/ (root)` folder. GitHub will provide the live URL after deployment.
